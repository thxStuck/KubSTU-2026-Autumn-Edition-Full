## 🍂 关于

**KubSTU CTF 2026 — Autumn Edition** 是由库班国立技术大学（FITK）**Capybaras** 战队主办的国际网络安全竞赛。本仓库是 **官方的题解与赛题资料合集**：涵盖 **9 个类别** 的 **64 道题目**，包含原始题目描述、附件文件以及分步解答。

> Hack for fun, not for profit.

## 📁 仓库结构

每道题目都这样组织，让你同时看到题目与解答：

```text
<类别>/
└─ <题目>/
   ├─ Задание + файл/    ← 题目描述 + 附件文件
   └─ Решение/           ← 题解 / 解答
```

部分类别仍沿用旧的扁平结构（题目文件夹内的 `README.md` / `writeup.md`）——我们正在逐步迁移到上面的结构。

---

## 🧭 使用方法

1. 从上面的表格中选择一个 **类别**。
2. 打开某个 **题目** 文件夹。
3. 在 `Задание + файл/` 中阅读 **题目**、获取其文件，然后对照 `Решение/` 中的 **解答**。
