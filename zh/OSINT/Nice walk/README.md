## 📌 题目

有一次我在一座美丽的南方城市散步，注意到了这尊漂亮的雕像，可惜我忘了这位女神的名字。帮我回忆一下：我是在哪里见到她的，她又叫什么名字？

![nice_walk.jpg](../../../assets/OSINT/Nice%20walk/nice_walk.jpg)

Flag 格式 — `KubSTU{Zeus:Mineralnye_Vody}`

**文件：** [nice_walk.jpg](../../../assets/OSINT/Nice%20walk/nice_walk.jpg)

## 🏁 解答

### 第 1 步：分析照片

雕像：
一尊古典风格的白色少女（或女神）雕像。她手里拿着一个像是碗或灯的物件。

周围环境：
背景可见一栋 2–3 层的现代建筑。雕像旁边有一处整洁的花坛，种着银白色的植物——公园里常见的典型观赏种植。

自然景物：
天气晴朗。树上的叶子呈黄色和绿色，表明季节是初秋或仲秋。

### 第 2 步：初步结论

基于这些细节，可以较有把握地推断：照片拍摄于某个公园或林荫道，位置靠近疗养院、酒店或度假区。

### 第 3 步：缩小地理范围

建筑风格和场地布置暗示这是南方地区。然而照片里没有棕榈树和其他亚热带植物，而这些通常出现在海滨步道和度假地。由此可排除沿海城市，聚焦于内陆的南方城市。

### 第 4 步：借助外部资源核实

我们把照片上传到 google.com 的“以图搜图”（Search by image）服务。

![google_search.png](../../../assets/OSINT/Nice%20walk/google_search.png)

结果中出现几张相似图片，据此得以确定照片中是古希腊女神 Hebe（Геба）的雕像。

### 第 5 步：最终搜索

我们在地图上搜索“手持碗的少女 南方城市”/“Hebe 女神 南方城市”。服务返回一座位于 Goryachy Klyuch 市的纪念像。这正是我们要找的地点。
