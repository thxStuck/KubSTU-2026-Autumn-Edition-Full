## 📁 रिपॉज़िटरी संरचना

हर चैलेंज इस तरह व्यवस्थित है कि आपको पहेली और उत्तर दोनों एक साथ मिलें:

```text
<श्रेणी>/
└─ <चैलेंज>/
   ├─ Задание + файл/    ← टास्क विवरण + संलग्न फ़ाइलें
   └─ Решение/           ← राइटअप / समाधान
```

कुछ श्रेणियाँ अभी भी पुराने सपाट लेआउट में हैं (चैलेंज फ़ोल्डर के अंदर `README.md` / `writeup.md`) — हम धीरे-धीरे सब कुछ ऊपर दिए गए ढाँचे में ला रहे हैं।

## 🧭 कैसे उपयोग करें

1. ऊपर दी गई तालिका से एक **श्रेणी** चुनें।
