# Honeyleaf

## 📌 कार्य

इंस्टेंस एक छोटी Flask सेवा है, एक "बेकरी रसीद संग्रह", जो http://159.194.244.226:8083/ पर है। मुख्य पेज पर दस फ़ाइलें हैं: पाँच रसीदें और पाँच macOS `._*` टुकड़े। हेडर में "कैश काउंटर" का एक लिंक भी है, लेकिन सक्रिय रूट सिर्फ़ दो हैं: `/` जो सूची दिखाता है और `/view?file=<नाम>` जो कोई फ़ाइल दिखाता है।

## 🏁 समाधान

`/view` के अंदर पथ `os.path.join(RECEIPTS_DIR, name)` से बनाया जाता है, जहाँ `name` सीधे query string से लिया जाता है। `os.path.join` में एक एब्सोल्यूट पथ बेस फ़ोल्डर को ओवरराइड कर देता है, और `../` को कोई नहीं हटाता। एक क्लासिक आर्बिट्रेरी फ़ाइल रीड:

```bash
curl 'http://159.194.244.226:8083/view?file=/flag.txt'
# kubstu{h0n3yl34f_p4th_tr4v3rs4l_defd1128}
```

इसी बग से सर्वर का सोर्स भी निकाल लिया: `/view?file=/proc/self/cwd/app.py`। कमज़ोर जगह के ठीक बगल में डेवलपर का एक TODO भी छूटा हुआ था कि वैलिडेशन "अभी जोड़नी बाक़ी है"। पक्का करने के लिए `../../../flag.txt` और `/proc/self/root/flag.txt` भी जाँचे — सामग्री वही निकली।

बाक़ी सब कुछ खाली है: रसीदें अपनी कुल राशि के हिसाब से मेल खाती हैं, `._*` फ़ाइलें सामान्य 177-बाइट AppleDouble ब्लॉक हैं, और रूट `/download`, `/counter`, `/admin`, `/api` सब 404 लौटाते हैं। फ़्लैग सेवा ख़ुद ही दे देती है; एक ही रिक्वेस्ट काफ़ी है।

**फ्लैग:** `kubstu{h0n3yl34f_p4th_tr4v3rs4l_defd1128}`
