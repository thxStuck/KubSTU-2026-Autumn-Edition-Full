# Matryoshka

## 📌 कार्य

साथ में सिर्फ़ एक फ़ाइल मिलती है — matryoshka.zip, और उसके अंदर दस ZIP एक-दूसरे में नेस्ट किए हुए हैं। हर स्तर पर एक README (रूसी और अंग्रेज़ी) और अगली `levelNN.zip` पासवर्ड के साथ पड़ी होती है। README बताता है कि खुले स्तर के डेटा से अगला पासवर्ड कैसे निकालें: कहीं यह किसी पेचीदा एन्कोडिंग में आर्काइव कमेंट है, कहीं note.txt, कहीं candidates.txt। पहला आर्काइव बिना पासवर्ड के है, उसके बाद सभी स्तर ZipCrypto पर हैं।

## 🏁 समाधान

पूरी श्रृंखला इस तरह दिखती है:

1. matryoshka.zip: कमेंट `5ox5iae8pv05` — level02 का पासवर्ड।
2. `emhhZzEwdWN0NHc2ag==` — base64, देता है `zhag10uct4w6j`।
3. `795f3274787a376a38766569796c73` — hex, देता है `y_2txz7j8veiyls`।
4. `fl8insn09afrrlg` — ROT13, मिलता है `sy8vafa09nseeyt`।
5. कोई कमेंट नहीं; note.txt में दूसरी पंक्ति पासवर्ड है `zjcp1s35m_q5`।
6. `cza2gkmpru` को उल्टा करने पर — `urpmkg2azc`।
7. `120 57 115 104 56 111 117 103 105 55 50 48 107` — दशमलव वर्ण कोड, मिलता है `x9sh8ougi720k`।
8. candidates.txt में छह पंक्तियाँ हैं; तीसरी फ़िट होती है: `nhd7rpralyg`।
9. `GBUHGMDLGZ4TQMJQ` — base32, देता है `0hs0k6y810`।
10. level10.zip में flag.txt फ़्लैग के साथ पड़ी है।

इसे हाथ से करना मज़ेदार नहीं, इसलिए एक स्क्रिप्ट लिखी: यह मौजूदा आर्काइव का कमेंट लेती है, सभी समर्थित रूपांतरण (plain, base64, hex, ROT13, reverse, दशमलव कोड, base32 और हर वेरिएंट का reverse) निकालती है, note.txt और candidates.txt की पंक्तियाँ मिलाती है, और नेस्टेड आर्काइव खुलने तक एक-एक करके उम्मीदवार आज़माती है। कोड में कहीं भी पासवर्ड हार्डकोड नहीं हैं — स्क्रिप्ट शून्य से सभी दस स्तर पार करती है:

```
$ python3 solve.py matryoshka.zip out
    ...
    FLAG: kubstu{t3n_l4y3rs_d33p_991939c0}
```
