## 🏁 समाधान

### विवरण

Subway Surfers के रन की वीडियो रिकॉर्डिंग वाला एक आर्काइव दिया गया है (जैसा कि कार्य [Subway 2](../Subway%202/) में)। कोई स्पष्ट टेक्स्ट नहीं है — जानकारी इस बात में एन्कोड की गई है कि स्क्रीन पर क्या हो रहा है।

### विचार

प्रत्येक वीडियो में आपको उन **वैगनों (ट्रेनों) की संख्या गिननी है**, जिनके पास से / ऊपर से पात्र गुज़रता है। प्राप्त संख्या फ़्लैग के एक अक्षर का **दशमलव ASCII कोड** है।

वीडियो के अक्षरों को **क्रम में** जोड़ने पर फ़्लैग मिल जाता है।

```
видео_1 -> N1 вагонов -> chr(N1)
видео_2 -> N2 вагонов -> chr(N2)
...
флаг = chr(N1) + chr(N2) + ... 
```

### चरण-दर-चरण कैसे हल करें

1. आर्काइव को अनपैक करें, वीडियो को नाम के अनुसार क्रमबद्ध करें (क्रम महत्वपूर्ण है — यह अक्षरों का क्रम निर्धारित करता है)।
2. प्रत्येक वीडियो के लिए एक रन में वैगनों की संख्या गिनें। वीडियो को फ़्रेमों में बाँटकर मैन्युअल या अर्ध-स्वचालित रूप से गिनना सुविधाजनक है:
   ```bash
   # по одному видео: нарезать кадры (например, 5 кадров в секунду) для удобного подсчёта
   ffmpeg -i "video_01.mp4" -vf fps=5 frames_01/%04d.png
   ```
3. प्रत्येक संख्या को ASCII तालिका के अनुसार एक अक्षर में बदलें और स्ट्रिंग इकट्ठा करें।

### डिकोडर स्क्रिप्ट

जैसे ही वीडियो के अनुसार वैगनों की संख्या (फ़ाइल क्रम में) ज्ञात हो जाती है, फ़्लैग इस तरह इकट्ठा होता है:

```python
# counts — список: количество вагонов в каждом видео, по порядку
counts = [
    # 75, 85, 66, 83, 84, 85, 123, ...   # пример: K U B S T U {
]

flag = "".join(chr(n) for n in counts)
print(flag)
```

शुद्धता की जाँच शुरुआत से करना आसान है: पहली संख्याओं से `KubSTU{` बनना चाहिए — यानी `75 85 66 83 84 85 123`। यदि शुरुआत मेल नहीं खाती — तो कहीं गिनती या फ़ाइलों का क्रम गड़बड़ है।

### फ़्लैग

```
KubSTU{...}
```
> सटीक मान आर्काइव के वीडियो पर निर्भर करता है (अभी वे हमारे पास उपलब्ध नहीं हैं)।
> `counts` भरते ही यह ऊपर दी गई स्क्रिप्ट द्वारा स्वचालित रूप से इकट्ठा हो जाता है।
