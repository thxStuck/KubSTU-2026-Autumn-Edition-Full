### विवरण

Subway श्रृंखला की अगली कड़ी। वीडियो में **दो रंगों के वैगन — पीले और लाल** दिखाई देते हैं।

### विचार

- **पीले वैगन विभाजक हैं** (अक्षरों के बीच सीमांकक)।
- **लाल वैगन गिने जाते हैं**: पीले विभाजकों के बीच किसी खंड में लाल वैगनों की संख्या एक अक्षर का **ASCII कोड** है।
- खंडों के सभी अक्षर, क्रम में इकट्ठा किए गए, फ़्लैग देते हैं।

```
... R R R R Y R R ... R R ... Y R R R ...
    └── 4 ──┘       └─ ? ─┘    └── 3 ──┘
     chr(4)          chr(?)      chr(3)
```

अर्थात वैगनों की धारा को क्रम में पढ़ें: पीला = «अक्षर का अंत / सीमा», सीमाओं के बीच लाल की संख्या = अक्षर का मान।

### चरण-दर-चरण कैसे हल करें

1. आर्काइव को अनपैक करें, वीडियो को नाम के अनुसार क्रमबद्ध करें।
2. वीडियो से गुज़रें और वैगनों का क्रम उनके रंग सहित लिखें (R — लाल, Y — पीला)। गिनती के लिए फ़्रेम काटना सुविधाजनक है:
   ```bash
   ffmpeg -i "video.mp4" -vf fps=5 frames/%04d.png
   ```
3. लाल के क्रम को पीले विभाजकों के अनुसार बाँटें, प्रत्येक «लाल» खंड की लंबाई गिनें।
4. प्रत्येक लंबाई को एक अक्षर (`chr`) में बदलें और फ़्लैग इकट्ठा करें।

### डिकोडर स्क्रिप्ट

```python
# seq — последовательность вагонов по порядку: 'R' (красный) и 'Y' (жёлтый-разделитель)
seq = "RRRR" "Y" "RR" "Y"  # ... и так далее

segments = seq.split("Y")              # делим по жёлтым разделителям
counts = [len(s) for s in segments if s != ""]  # число красных в каждом сегменте
flag = "".join(chr(n) for n in counts)
print(counts)
print(flag)
```

यदि सीधे संख्याओं में गिनना अधिक सुविधाजनक है (प्रत्येक समूह में कितने लाल):

```python
red_counts = [75, 85, 66, 83, 84, 85, 123]  # пример: даёт 'KubSTU{'
print("".join(chr(n) for n in red_counts))
```

जाँच: पहले समूहों से `KubSTU{` बनना चाहिए → `75 85 66 83 84 85 123`।

### फ़्लैग

```
KubSTU{...}
```
> सटीक मान आर्काइव के वीडियो पर निर्भर करता है। गिने गए `red_counts` को स्क्रिप्ट में डालें।

### टिप्पणियाँ

- Subway 2/3 से मुख्य अंतर: यहाँ **दो रंग** हैं — पीला मान में नहीं गिना जाता, वह केवल अक्षर की सीमा चिह्नित करता है।
- ध्यान रखें कि खाली खंड (लगातार दो पीले) गिनती में न आएँ, जब तक कि शर्त के अनुसार वे `chr(0)` एन्कोड न करते हों।
