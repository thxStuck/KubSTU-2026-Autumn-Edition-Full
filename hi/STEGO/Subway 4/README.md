### विवरण

Subway श्रृंखला का समापन। पिछले हिस्सों के विपरीत, कुछ गिनने की ज़रूरत नहीं है — **फ़्लैग सीधे वीडियो के फ़्रेमों में, अंधेरे में छिपा है**। सामान्य चमक पर यह दिखाई नहीं देता (बहुत गहरे पिक्सेल काले बैकग्राउंड में लगभग मिल जाते हैं)।

### विचार

आपको **छायाओं को खींचना / चमक और कंट्रास्ट बढ़ाना** है, और गहरे हिस्सों में फ़्लैग का टेक्स्ट प्रकट हो जाएगा।

### चरण-दर-चरण कैसे हल करें

#### विकल्प 1 — ffmpeg के माध्यम से (वीडियो में सीधे चमक/गामा/कंट्रास्ट बढ़ाना)

```bash
# сильно осветляем и тянем контраст, смотрим результат
ffmpeg -i subway4.mp4 -vf "eq=brightness=0.6:contrast=4:gamma=3" subway4_bright.mp4
```

आप `curves` के माध्यम से स्तरों (levels) को भी खींच सकते हैं:

```bash
ffmpeg -i subway4.mp4 -vf "curves=all='0/0 0.1/0.9 1/1'" subway4_levels.mp4
```

#### विकल्प 2 — फ़्रेम काटें और चित्रों को संसाधित करें

```bash
ffmpeg -i subway4.mp4 -vf fps=2 frames/%04d.png
```

फिर प्रत्येक फ़्रेम को उजला करें (Python/PIL), चमक और कंट्रास्ट बढ़ाते हुए:

```python
from PIL import Image, ImageEnhance
import glob, os

os.makedirs("bright", exist_ok=True)
for p in glob.glob("frames/*.png"):
    img = Image.open(p).convert("RGB")
    img = ImageEnhance.Brightness(img).enhance(5.0)   # поднять яркость
    img = ImageEnhance.Contrast(img).enhance(3.0)     # поднять контраст
    img.save(os.path.join("bright", os.path.basename(p)))
```

या फिर काले थ्रेशोल्ड को आक्रामक रूप से «काटें», ताकि कोई भी पूर्णतः-काला-नहीं पिक्सेल सफ़ेद हो जाए:

```python
from PIL import Image
img = Image.open("frames/0007.png").convert("L")
# всё, что ярче 8 из 255 — делаем белым; остальное чёрным
bw = img.point(lambda x: 255 if x > 8 else 0)
bw.save("frames/0007_threshold.png")
```

#### विकल्प 3 — इंटरैक्टिव रूप से

वीडियो/फ़्रेमों को किसी एडिटर (GIMP/Photoshop/कोई भी वीडियो एडिटर) में खोलें और मैन्युअल रूप से **Levels/Curves/Exposure** बढ़ाएँ — फ़्लैग सबसे गहरे फ़्रेमों में उभर आएगा।

### कहाँ देखें

फ़्लैग आमतौर पर सभी फ़्रेमों पर नहीं, बल्कि एक छोटे हिस्से पर दिखाई देता है। उजले किए गए वीडियो को पूरा देखें या सभी फ़्रेमों पर थ्रेशोल्ड प्रोसेसिंग चलाएँ और आँखों से `KubSTU{...}` टेक्स्ट वाले फ़्रेम को खोजें।

### टिप्पणियाँ

- कार्य का सार गणित नहीं, बल्कि विशेष रूप से **चमक/कंट्रास्ट/स्तरों** के साथ काम करना है।
- यदि एकसमान फ़िल से मदद न मिले, तो R/G/B चैनलों में विभाजित करके देखें — टेक्स्ट केवल एक ही चैनल में छिपा हो सकता है।
