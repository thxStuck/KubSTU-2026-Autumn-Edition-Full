# Grep: almost but not quite

> **श्रेणी:** DevSecOps / Git · **कठिनाई:** Easy · **इवेंट:** KubSTU CTF 2026 Autumn

## 📌 कार्य

सुरक्षा टीम ने संदिग्ध गतिविधि पकड़ी है: प्रोडक्शन परिवेश से सर्विस कीज़ लीक हो गई हैं। एक डेवलपर का दावा है कि उसने गलती को समय रहते देख लिया, बदलावों को वापस (revert) कर दिया, और उसका कहना है कि साफ़ रिपॉज़िटरी में अब वह सीक्रेट मौजूद नहीं है।

लेकिन सुरक्षा टीम उससे सहमत नहीं है। उन्होंने आपको यह आर्काइव दिया है और उसी सर्विस की (key) को ढूँढने के लिए कहा है जिसकी वह बात कर रहा है।

## 🏁 समाधान

यह कार्य एक डैंगलिंग (dangling) कमिट पर आधारित है।

1. आर्काइव को अनज़िप करें।
2. टर्मिनल में `git fsck --lost-found` चलाएँ। आपको संदेश मिलेगा `dangling commit 3bdea0f23e83a6a3757ae2b7c7b781c174493d26`।
3. अब इस कमिट को देखें: `git show 3bdea0f23e83a6a3757ae2b7c7b781c174493d26`
