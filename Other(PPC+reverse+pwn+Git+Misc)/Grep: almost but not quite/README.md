# RU
### Название: Grep: almost but not quite

### Категория: DevSecOps / Git

### Сложность: Easy

### Описание:

Служба безопасности зафиксировала подозрительную активность: из продакшн-контура утекли сервисные ключи. Разработчик клянется, что вовремя заметил ошибку, сделал откат изменений и в чистом репозитории секрета больше нет.

Однако безопасники с ним не согласны. Они передали Вам этот архив и попросили отыскать тот самый сервисный ключ.

Формат флага: KubCTF{...}

# EN

### Title: Grep: almost but not quite

### Category: DevSecOps / Git

### Difficulty: Easy

### Description:

The security team has detected suspicious activity: service keys have leaked from the production environment. A developer claims to have noticed the error promptly, reverted the changes, and insists that the secret is no longer present in the clean repository.

However, the security team disagrees with him. They provided you with this archive and asked you to find the very service key he's talking about.

Flag format: KubCTF{...}
