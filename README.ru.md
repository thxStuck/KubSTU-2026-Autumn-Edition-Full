## 📁 Структура репозитория

Каждое задание разложено так, чтобы рядом были и условие, и решение:

```text
<Категория>/
└─ <Задача>/
   ├─ Задание + файл/    ← условие + прикреплённые файлы
   └─ Решение/           ← райтап / решение
```

Часть категорий пока в прежнем «плоском» виде (`README.md` / `writeup.md` внутри папки задачи) — мы постепенно переводим всё к структуре выше.

---

## 🧭 Как пользоваться

1. Выберите **категорию** из таблицы выше.
2. Откройте папку **задачи**.
3. Прочитайте **условие** в `Задание + файл/`, заберите файлы и сверьтесь с **решением** в `Решение/`.
