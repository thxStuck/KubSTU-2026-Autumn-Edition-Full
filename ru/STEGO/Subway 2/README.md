# Subway 2

> **Категория:** Hardware / Stego · **Событие:** KubSTU CTF 2026: Autumn
> Пользовательский райтап команды **mpei_larpers** (tg: [@kunstl3r](https://t.me/kunstl3r)) · Источник: https://ctftime.org/writeup/41129 (CTFtime, пользовательский райтап)

## 📌 Задание

Нам даётся архив из 24 mp4-роликов с игровым процессом Subway Surfers. Найдите спрятанный флаг.

## 🏁 Решение

Чтобы получить флаг, нужно записать, сколько монет в итоге собрано за забег в каждом видео. Количество монет в каждом видео — это десятичный ASCII-код одного символа флага, в порядке следования видео.

```
75 85 66 83 84 85 123 49 116 53 95 114 51 97 49 95 115 117 98 119 119 51 105 125
```

Переведя каждое число в соответствующий символ ASCII, получаем флаг.

**Флаг:** `KUBSTU{1t5_r3a1_subww3i}`
