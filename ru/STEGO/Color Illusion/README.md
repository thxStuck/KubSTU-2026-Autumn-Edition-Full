# Color Illusion

> **Категория:** Hardware / Stego · **Событие:** KubSTU CTF 2026 Autumn · **#263**
> Автор задания: [@van_1pi](https://t.me/van_1pi)

## 📌 Задание

Художник утверждает, что в этой картине скрыто послание.
«Не все цвета такие, какими кажутся», — загадочно сказал он.

**Файлы:** [stego-easy.zip](../../../assets/STEGO/Color%20Illusion/stego-easy.zip)

## 🏁 Решение

Распакуйте архив и откройте `colors.gif`. Подсказка («не все цвета такие, какими кажутся») указывает на **значения цветов**, а не на видимое изображение. Исследуйте цветовые плоскости / палитру картинки — например, через **Aperisolve**, **Stegsolve** (просмотр битовых плоскостей) или выгрузив палитру — и флаг складывается из аномальных цветовых записей.

**Флаг:** `KubSTU{Pr0bAbly_ea8y_steG0}`
