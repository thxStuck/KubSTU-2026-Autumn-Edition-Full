## 🏁 Решение

> **Статус:** Метод решения ✅

### Описание

Дан архив с видеозаписями забегов в Subway Surfers (как в задаче [Subway 2](../Subway%202/)). Явного текста нет — информация закодирована тем, что происходит на экране.

### Идея

В каждом видео нужно **посчитать количество вагонов (поездов)**, мимо/по которым проезжает персонаж. Полученное число — это **десятичный ASCII-код** одного символа флага.

Складывая символы по видео **по порядку**, получаем флаг.

```
видео_1 -> N1 вагонов -> chr(N1)
видео_2 -> N2 вагонов -> chr(N2)
...
флаг = chr(N1) + chr(N2) + ... 
```

### Как решать по шагам

1. Распаковать архив, отсортировать видео по имени (порядок важен — он задаёт порядок символов).
2. Для каждого видео посчитать количество вагонов за забег. Удобно разбить видео на кадры и считать вручную либо полуавтоматически:
   ```bash
   # по одному видео: нарезать кадры (например, 5 кадров в секунду) для удобного подсчёта
   ffmpeg -i "video_01.mp4" -vf fps=5 frames_01/%04d.png
   ```
3. Перевести каждое число в символ по таблице ASCII и собрать строку.

### Скрипт-декодер

Как только посчитаны количества вагонов по видео (в порядке файлов), флаг собирается так:

```python
# counts — список: количество вагонов в каждом видео, по порядку
counts = [
    # 75, 85, 66, 83, 84, 85, 123, ...   # пример: K U B S T U {
]

flag = "".join(chr(n) for n in counts)
print(flag)
```

Корректность легко проверить по началу: первые числа должны дать `KubSTU{` — то есть `75 85 66 83 84 85 123`. Если начало не совпало — где-то сбит подсчёт или порядок файлов.

### Флаг

```
KubSTU{...}
```
> Точное значение зависит от видео из архива (у нас их сейчас нет под рукой).
> Соберётся автоматически скриптом выше, как только заполнены `counts`.

### Примечания

- Это та же механика, что в Subway 2 (там считали монеты), но здесь считаются **вагоны**.
- Главный источник ошибок — сбитый порядок файлов и пропущенные/задвоенные вагоны; сверяйтесь с префиксом `KubSTU{`.
