# Biba 'n Boba

> **Категория:** OSINT · **Событие:** KubSTU CTF 2026 Autumn

## 📌 Задание

![biba_boba.jpg](../../../assets/OSINT/Biba%20'n%20Boba/biba_boba.jpg)

Где-то на территории университета живут двое. Они ничего не говорят, никуда не уходят и смотрят на всех во внутреннем дворе уже несколько месяцев. Университет не смог удержаться, чтобы не рассказать о них — загляни в официальные аккаунты.

Флагом будет ссылка на пост из телеграм-канала университета.

**Файлы:** [biba_boba.jpg](../../../assets/OSINT/Biba%20'n%20Boba/biba_boba.jpg)

## 🏁 Решение

### Шаг 1. Первичный осмотр

У нас на фото представлен небольшой арт-объект, два камня с глазами. Вроде объект не примечательный, но из описания мы понимаем, что университет о них рассказал.

### Шаг 2. Поиск

Исходя из вышесказанного идём в соц. сети университета: vk.com/kubstu_official или t.me/kubstu_official. На официальных страницах начнём с поиска по ключевым словам: `камень, камни, двое и т.д`.

![search_res.png](../../../assets/OSINT/Biba%20'n%20Boba/search_res.png)

Буквально первый же результат в выдаче привлекает внимание.

![searched_post.png](../../../assets/OSINT/Biba%20'n%20Boba/searched_post.png)
