## 📌 Задание

fw.bin — 16608 байт RV32-прошивки под машину в стиле QEMU virt: UART на 0x10000000, SiFive-финишер на 0x100000, payload грузится в 0x80100000.

## 🏁 Решение

Первые 0xDC байт — бутлоадер прямо во флеше: он хэширует собственный код вариантом FNV-1a (h = rol32((h ^ word) * 0x01000193, 13), база 0x811c9dc5, ноль заменяется на 0xdeadbeef), этим хэшем сидит xorshift32 и XOR-расшифровывает следующие 0x4000 байт в RAM, после чего прыгает туда.

Расшифрованный payload — прошивка «TR4P-G4T3»: спрашивает по UART 16-символьный ключ и проверяет его преобразованием в духе Фейстеля, восемь раундов над двумя 8-байтовыми половинами, всё крутится вокруг RC4-таблицы и 64 байт кейстрима из фиксированного ключа tr4p_d1sp4tch_v1. Преобразование биективное, поэтому валидный пароль восстанавливается инверсией от зашитого в прошивке целевого буфера: RV32-TR4P-G4T3S!. На успехе прошивка сама выводит флаг: RC4 от финального 16-байтного состояния как ключа, 39 байт PRGA, XOR с 39-байтной маской из rodata.

Отдельная фишка — самодельный механизм вызовов поверх нелегальных инструкций (opcode 0x7f): 0x00X0007F кладёт адрес возврата в стек и прыгает через таблицу диспетчера на 0x801008bc, 0x0000107F возвращает управление. Флаг про «ловушки как настоящий control flow» как раз про это.

По ходу решения:

- Стадия 1 воспроизведена питоном: хэш над [0x00, 0xDC), xorshift32, XOR диапазона [0xE0, 0x40E0) → pay.bin. Из расшифрованного payload достаются строки TR4P-G4T3 bootstrap ok, key>, granted:, denied и RC4-ключ.

- Функции init/check/compare прогнал в Unicorn ([emu_crypto.py](http://emu_crypto.py)) как оракул — снял S-бокс и 64 байта кейстрима для оффлайн-модели.

- Инверсия check: каждый раунд обратим (B_r = A_{r+1}, A_r = B_{r+1} ^ acc), из целевого буфера на 0x801008ac получается единственный пароль RV32-TR4P-G4T3S!. Форвард-проверка дала байт-в-байт целевые 8feda32565e6ca9a79578cd1e7b0e0fc и финальное состояние 9d1084ba84b1d2bfb93c5d75c2b889bd.

- Флаг (ветка granted на 0x80100460) собран оффлайн той же логикой, что и в прошивке: RC4-KSA от финального состояния, 39 байт PRGA, XOR с маской на 0x80100884.

- Доказательство end-to-end: [e2e_emu.py](http://e2e_emu.py) загружает немодифицированный fw.bin в Unicorn (с эмуляцией ловушек и UART), сам набирает пароль и получает от прошивки:

```
TR4P-G4T3 bootstrap ok
      key> RV32-TR4P-G4T3S!
      granted: KubSTU{tr4ps_4r3_th3_r34l_c0ntr0l_fl0w}
```

плюс запись 0x5555 в SiFive-финишер — признак успеха. [crosscheck.py](http://crosscheck.py) сверяет строку из эмулятора с оффлайн-решением: MATCH.
