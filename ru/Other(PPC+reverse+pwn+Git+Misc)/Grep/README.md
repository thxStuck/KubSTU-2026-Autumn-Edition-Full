# Grep: almost but not quite

> **Категория:** DevSecOps / Git · **Сложность:** Easy · **Событие:** KubSTU CTF 2026 Autumn

## 📌 Задание

Служба безопасности зафиксировала подозрительную активность: из продакшн-контура утекли сервисные ключи. Разработчик клянётся, что вовремя заметил ошибку, сделал откат изменений и в чистом репозитории секрета больше нет.

Однако безопасники с ним не согласны. Они передали вам этот архив и попросили отыскать тот самый сервисный ключ.

Формат флага: KubCTF{...}

**Файлы:** [ctf_repo.zip](../../../assets/Other(PPC+reverse+pwn+Git+Misc)/Grep/ctf_repo.zip)

## 🏁 Решение

Основа задачи — висячий (dangling) коммит.

1. Распакуйте архив.
2. Выполните в терминале `git fsck --lost-found`. Вы получите сообщение `dangling commit 3bdea0f23e83a6a3757ae2b7c7b781c174493d26`.
3. Теперь посмотрите этот коммит: `git show 3bdea0f23e83a6a3757ae2b7c7b781c174493d26`
