# Timing

> **Категория:** Forensics · **Событие:** KubSTU CTF 2026 Autumn

## 📌 Задание

Дан образец для анализа. Его нужно открыть и восстановить флаг.

## 🏁 Решение

Образец необходимо открыть для анализа, например в autopsy.

Объекты `draft_notes.tmp` и `unused_ledger.tmp` являются небольшими отвлекающими записями. В корне файловой системы находится удалённый `sync_7D3.tmp`; соседний журнал `Logs/TRANSFER.LOG` связывает этот объект с последней операцией Batch 7D3.

Несмотря на расширение `.tmp`, определение по магическому числу обозначает целевой файл как **PE32 executable**. В Autopsy его следует сохранить через контекстное действие Extract File(s). Размер правильного файла — **14 848 байт**, а его первые байты — `4D 5A` (`MZ`). Оригинальное имя может отображаться с восстановленным первым символом или с пометкой об удалении: это нормальное следствие FAT-записи и не влияет на извлечение.

В функции, которая формирует буфер перед вызовом `fwrite`, присутствуют два коротких массива байтов. Сначала они объединяются и для каждого байта с индексом `i` выполняется операция:

```text
shuffled[i] = encoded[i] XOR ((0x51 + 0x23 × i) mod 256)
```

Далее меняются местами первые два блока по 16 байт, а остаток копируется без изменений:

```text
plain[0:16]   = shuffled[16:32]
plain[16:32]  = shuffled[0:16]
plain[32:]    = shuffled[32:]
```

После этих действий получается:

```text
KubSTU{aU70p5y_D3l373d_P3_4nd_r3v3r53}
```

**Флаг:** `KubSTU{aU70p5y_D3l373d_P3_4nd_r3v3r53}`
