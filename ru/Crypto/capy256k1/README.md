# capy256k1

## 📌 Задание

Вместо стандартной secp256k1 лаборатория выкатила свою 256-битную кривую в `capy256k1.py`, вместе с `output.json`, где лежат несколько диагностических точек и для каждой — результирующая точка `R = secret · point`. Восстановите секрет и расшифруйте флаг.

**Файлы:** [generate.py](../../../assets/Crypto/capy256k1/generate.py), [solve.py](../../../assets/Crypto/capy256k1/solve.py), [SECRETS.txt](../../../assets/Crypto/capy256k1/SECRETS.txt)

## 🏁 Решение

### Суть
Самодельная арифметика в `capy256k1.py` **нигде не проверяет, что точка лежит на кривой**. Это классическая **invalid curve attack**.

Лаборатория выкатила не стандартную secp256k1, а свою 256-битную кривую (`a = 0`, своё простое `p` специального вида `2²⁵⁵ + c`). Важное отличие: **простое НЕ выбрано twist-secure**. У кривых с j-инвариантом 0 секстик-твисты `y² = x³ + b` имеют один из шести порядков, задаваемых CM-представлением `4p = L² + 27M²`. У этого `p` несколько твистов несут подгруппу **простого порядка `q` в диапазоне 2³⁴…2³⁹**.

`output.json` содержит несколько диагностических точек, для каждой — результирующую точку `R = secret · point`. Точки лежат не на базовой кривой, а на этих слабых твистах.

Здесь подгруппы специально подняты в диапазон 2³⁴…2³⁹. Линейный проход (`q` операций) — миллиарды сложений точек, в чистом Python это часы-дни, то есть **перебором не берётся**. Нужна настоящая связка инструментов:

1. **Распознать invalid curve** — нет проверки on-curve.
2. **Прочитать `b = y² − x³ (mod p)`** для каждой точки (`a = 0`).
3. **Посчитать порядок твиста без Sage** — CM-метод `4p = L² + 27M²` (cornacchia даёт `(L, M)`, отсюда шесть кандидатов-порядков); выбрать тот, что аннигилирует точку.
4. **Вытащить `q`** — факторизовать порядок (trial division + Pollard rho / ECM), найти простой множитель с `q·point = O`.
5. **ECDLP в подгруппе ⟨point⟩** — baby-step/giant-step (или Pollard rho / kangaroo), `O(√q) ≈ 2¹⁷…2²⁰`, из `R = secret·point` получить `secret mod q`.
6. **CRT** по четырём вычетам.

Секрет 128-битный; произведение четырёх `q` даёт **142-битный** CRT-модуль `> 2¹²⁸`, значение единственно. Дальше `decrypt_flag(secret, ciphertext)`.

Sage ускоряет шаги 3–5, но **не обязателен**: весь путь проходится на чистом Python (cornacchia + rho + BSGS + CRT).
