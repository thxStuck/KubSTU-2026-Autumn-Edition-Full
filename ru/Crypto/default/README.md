# default

> **Категория:** Crypto · **Событие:** KubSTU CTF 2026 Autumn

## 📌 Задание

`output.txt` содержит два больших числа — модуль RSA `n` и шифртекст `c`. Открытая экспонента `e` не дана. Восстановите открытый текст.

**Файлы:** [solve.py](../../../assets/Crypto/default/solve.py)

## 🏁 Решение

### Наблюдения
- Два больших числа + название «Default» → это RSA без padding'а.
- `e` не дана → скорее всего маленькая (иначе зачем скрывать).
- Классические кандидаты малой экспоненты: `3, 5, 7, 11, 13, 17`.

### Уязвимость
Small-exponent attack на одном шифртексте (частный случай атаки Хостада без padding'а).

Если сообщение `m` достаточно короткое, то `m^e < n`, и модульное возведение в степень фактически не срабатывает:

```
c = m^e mod n = m^e   (потому что m^e < n)
```

Значит, чтобы восстановить `m`, достаточно взять обычный целочисленный `e`-й корень из `c`.

Проверка размерностей: флаг ≈ 480 бит, `n` = 4096 бит → `m^e < n` для `e ∈ {3, 5, 7}`.

### Решение
Перебираем малые `e`, для каждого пробуем взять корень нацело и проверяем формат флага:

```python
from Crypto.Util.number import long_to_bytes
import gmpy2

# из output.txt: n, c
for e in [3, 5, 7, 11, 13, 17, 19, 23]:
    m, exact = gmpy2.iroot(c, e)
    if not exact:
        continue
    try:
        flag = long_to_bytes(int(m)).decode()
    except UnicodeDecodeError:
        continue
    if "KubSTU{" in flag:
        print(f"e = {e}")
        print(flag)
        break
```
