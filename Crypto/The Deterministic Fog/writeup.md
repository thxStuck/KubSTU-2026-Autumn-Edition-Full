
## Суть

Снаружи — честный LWE (`n=40, m=200, q=257`, шумная система). На деле LWE
решать не нужно: шум **детерминированный**. Его источник — публичный
**усечённый LCG**

```
x_{i+1} = (mult · x_i + inc) mod 2^48      (mult, inc, mod_bits — в output.json)
```

с секретным 48-битным сидом `x_0`. Прибор публикует короткий
**калибровочный след** `calibration` — старшие 8 бит первых 24 состояний
(`x_i >> 40`). По этому следу сид восстанавливается **решёткой** (классическая
реконструкция усечённого LCG, FHKLLS).

## Почему не берётся «в лоб»

- **Граница шума `bound = 100 > q/4 = 64`.** Шум нельзя «округлить», значит
  это **не** обычный small-noise LWE — generic-BDD-атака на LWE не работает,
  нужно воспроизвести точный поток шума.
- **Сид 48-битный** → перебор `2⁴⁸` мёртв.
- **В калибровке скрыто 40 младших бит** каждого выхода (показаны только 8
  старших) → перебор младших бит `2⁴⁰` тоже мёртв. Остаётся только решётка.
- Поэтому единственный путь к флагу идёт через решётку; её не обойти.

## Разбор

**Шаг 1. Восстановить сид решёткой.** Состояние линейно по `x_0`:
`x_i = α_i·x_0 + β_i (mod M)`, а `x_0 = (calib[0]·2⁴⁰) + l_0`, где `l_0` —
скрытые 40 бит. Из `x_i = (calib[i]·2⁴⁰) + l_i`, `0 ≤ l_i < 2⁴⁰`, строим
решётку на неизвестных `(l_0, …)` и ищем короткий вектор (LLL). 24 выборок
хватает с запасом; выход проверяем, прогнав LCG вперёд и сверив старшие биты.

**Шаг 2. Воспроизвести поток шума.** Из `x_0` прогоняем LCG: калибровка берёт
состояния `x_0…x_{23}`, рабочий поток шума продолжается с `x_{24}` (центрируем:
`e = x mod 201 − 100`). Первые `m=200` значений ушли в `b`, следующие
`len(flag)·8` — в шифртекст.

**Шаг 3. Снять LWE (теперь это линейная система).** Зная шум `e`, публичные
выборки дают `A·s = b − e (mod q)` — обычная линейная система над `F₂₅₇`,
решается Гауссом (`m=200 ≫ n=40`, решение единственно).

**Шаг 4. Расшифровать.** Для каждой строки шифртекста
`val = (c_j − e_{m+j} − ⟨R_j, s⟩) mod q`; бит `0`, если `val` ближе к `0`,
иначе `1` (кодирование `bit·⌊q/2⌋`). Собираем биты в флаг.
