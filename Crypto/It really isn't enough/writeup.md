
## Структура задачи

Три слоя, каждый требует отдельной атаки, плюс четыре ложных пути.

| Слой / ловушка | Механизм | Что происходит |
|---|---|---|
| Слой 1 (RSA A) | `d ≈ N^0.26` | Wiener не хватает → нужен Boneh-Durfee |
| Ловушка: ключ B | `d ≈ N^0.24` | Wiener ломает за секунду → `blob` = издёвка |
| Слой 2a (ct1) | AES-GCM, валидный тег | фейк-флаг `k3ep_1o0k1ng` |
| Слой 2b (ct2) | AES-GCM, тег сломан | наивный `decrypt_and_verify` падает |
| Ловушка: `d` в source | фейк-константа | хеш даёт неверный ключ |

Название — прямая подсказка к слою 1: обычного Wiener'а **it really isn't enough**.

---

## Слой 1 — Boneh-Durfee

У ключа A приватная экспонента `d ≈ N^0.26`:
- Wiener работает только при `d < N^0.25` → **не берёт**;
- Boneh-Durfee работает при `d < N^0.292` → **берёт**.

Ключ B — приманка с `d ≈ N^0.24`: классический Wiener ломает его мгновенно,
но `blob` под ним расшифровывается в строку-издёвку. Это отсекает тех, кто
рефлекторно кидается на первый знакомый паттерн (особенно LLM).

**Суть атаки.** Из `e·d ≡ 1 (mod φ)` и `φ = N + 1 − (p+q)` получаем
уравнение с малыми корнями:

```
f(x, y) = 1 + x·(A + y) ≡ 0  (mod e),   A = (N+1)/2,  y ≈ -(p+q)/2
```

`|x| ~ N^delta`, `|y| ~ N^0.5`. Строим решётку из x- и y-shift полиномов
(Herrmann–May), редуцируем LLL, берём резольвенту двух коротких векторов,
находим корень → восстанавливаем `d`, затем факторизуем `N` из `(e, d)`.

Расшифровав `enc_key` (RSA-OAEP) и `src_ct` (AES-GCM), получаем `source.py`.

## Слой 2 — nonce reuse + сломанный тег

`source.py` показывает:
- `key = SHA256(str(d))` — от **настоящего** `d`. Рядом лежит константа
  `d = 0x...` с комментарием "private exponent" — это **фейк** (ловушка);
  использовать нужно `d`, полученный из Boneh-Durfee.
- Два GCM-шифротекста с **одним nonce**.

**ct1** — валидный тег → расшифровывается в фейк-флаг `k3ep_1o0k1ng`.
Слопер сдаёт его и получает "неверно".

**ct2** — тот же nonce, но тег намеренно испорчен. `decrypt_and_verify`
бросит `ValueError`. Ключевое понимание: **GCM = CTR + GMAC**. Сломана
только целостность, не конфиденциальность — расшифровать можно в обход тега:

```python
real = AES.new(key, AES.MODE_GCM, nonce=nonce).decrypt(ct2[:-16])  # без verify
```

→ настоящий флаг.



Пайплайн: Boneh-Durfee → `d` → факторизация → RSA-OAEP → AES-GCM(source)
→ парсинг nonce/ct → `SHA256(str(d))` → `decrypt` без verify на ct2.
