

## Что дано
`codes.txt` со строкой чисел через пробел:
`75 117 98 83 84 85 123 ...`

## Идея
Это ASCII-коды символов в десятичной системе. Каждое число — код одной
буквы. Подсказка: `75` = `K`, `117` = `u`, `98` = `b` → уже видно `Kub…`.

## Решение
Перевести каждое число в символ:

```python
codes = open("codes.txt").read().split()
flag = "".join(chr(int(x)) for x in codes)
print(flag)
```
