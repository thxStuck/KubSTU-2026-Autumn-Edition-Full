# [STEGO] Subway 4

- **Категория:** STEGO
- **Событие:** KubSTU CTF 2026: Autumn
- **Статус:** ✅ Метод решения

## Описание

Финал серии Subway. В отличие от предыдущих частей, считать ничего не нужно — **флаг спрятан прямо в кадрах видео, в темноте**. На обычной яркости он не виден (очень тёмные пиксели почти сливаются с чёрным фоном).

## Идея

Нужно **вытянуть тени / поднять яркость и контраст**, и в тёмных участках проявится текст флага.

## Как решать по шагам

### Вариант 1 — через ffmpeg (поднять яркость/гамму/контраст прямо в видео)

```bash
# сильно осветляем и тянем контраст, смотрим результат
ffmpeg -i subway4.mp4 -vf "eq=brightness=0.6:contrast=4:gamma=3" subway4_bright.mp4
```

Можно также растянуть уровни через `curves`:

```bash
ffmpeg -i subway4.mp4 -vf "curves=all='0/0 0.1/0.9 1/1'" subway4_levels.mp4
```

### Вариант 2 — нарезать кадры и обработать картинки

```bash
ffmpeg -i subway4.mp4 -vf fps=2 frames/%04d.png
```

Затем осветлить каждый кадр (Python/PIL), усилив яркость и контраст:

```python
from PIL import Image, ImageEnhance
import glob, os

os.makedirs("bright", exist_ok=True)
for p in glob.glob("frames/*.png"):
    img = Image.open(p).convert("RGB")
    img = ImageEnhance.Brightness(img).enhance(5.0)   # поднять яркость
    img = ImageEnhance.Contrast(img).enhance(3.0)     # поднять контраст
    img.save(os.path.join("bright", os.path.basename(p)))
```

Либо агрессивно «обрезать» чёрный порог, чтобы любой неидеально-чёрный пиксель стал белым:

```python
from PIL import Image
img = Image.open("frames/0007.png").convert("L")
# всё, что ярче 8 из 255 — делаем белым; остальное чёрным
bw = img.point(lambda x: 255 if x > 8 else 0)
bw.save("frames/0007_threshold.png")
```

### Вариант 3 — интерактивно

Открыть видео/кадры в редакторе (GIMP/Photoshop/любой видеоредактор) и вручную поднять **Levels/Curves/Exposure** — флаг проступит в самых тёмных кадрах.

## Где искать

Флаг обычно появляется не на всех кадрах, а на коротком участке. Просматривайте осветлённое видео целиком или прогоняйте пороговую обработку по всем кадрам и глазами ищите кадр с текстом `KubSTU{...}`.

## Флаг

```
KubSTU{...}
```
> Точное значение считывается с проявленного (осветлённого) кадра — видео у нас сейчас нет под рукой.

## Примечания

- Суть задачи — не математика, а именно работа с **яркостью/контрастом/уровнями**.
- Если ровная заливка не помогает, попробуйте разложить на каналы R/G/B — текст может быть спрятан только в одном канале.
