# Райтап: «Бро, прости»

## Условие

На заводе стих шум, но кое-что всё ещё работает на своих частотах. Найдите спрятанный флаг.

Формат флага: `KubSTU{...}`.

## Решение

Файл задания необходимо сначала проверить стандартными инструментами для стеганографии. В частности, полезно посмотреть метаданные PNG:

```bash
exiftool bro_stego_with_hint.png
```

В метаданных находится подсказка:

```text
stego_hint: key-bro
comment: Look into 8x8 frequency blocks
```

Из подсказки следует, что ключом является `bro`, а искать данные нужно в частотном представлении изображения, разбитого на блоки размером 8×8.

## DCT-стеганография

Для каждого блока изображения вычисляется **дискретное косинусное преобразование** (DCT). Оно переводит значения яркости пикселей в набор частотных коэффициентов.

В задании используется канал яркости изображения. Один скрытый бит определяется сравнением двух среднечастотных коэффициентов. Если первый коэффициент пары больше или равен второму, читается `1`; в противном случае читается `0`.

Используемые пары коэффициентов:

| Пара | Первый коэффициент | Второй коэффициент |
|---:|---:|---:|
| 1 | `(2, 3)` | `(3, 2)` |
| 2 | `(1, 4)` | `(4, 1)` |
| 3 | `(2, 4)` | `(4, 2)` |
| 4 | `(3, 3)` | `(4, 3)` |

Индексы отсчитываются от нуля. Выбор блока и пары выполняется в псевдослучайном порядке, построенном из ключа `bro`.

## Восстановление данных

Полученные биты объединяются в байты. Корректный поток начинается с сигнатуры:

```text
KSTU-DCT1
```

После сигнатуры идут длина сообщения, сам флаг и контрольная сумма CRC32. CRC нужна для проверки правильности ключа и целостности данных.

Для автоматического извлечения можно использовать приложенный скрипт:

```bash
python3 stego_dct.py decode bro_stego_with_hint.png --key bro
```

Результат:

```text
KubSTU{dct_clouds_hide_more_than_weather}
```

## Флаг

```text
KubSTU{dct_clouds_hide_more_than_weather}
```

## Вывод

Подсказка в метаданных указывает одновременно на ключ и направление поиска. Ключ `bro` задаёт порядок чтения блоков, а намёк на частоты приводит к DCT. После сравнения выбранных пар среднечастотных коэффициентов восстанавливается бинарная последовательность с флагом.
