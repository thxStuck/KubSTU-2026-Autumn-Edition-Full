## Описание

Продолжение серии Subway. На видео встречаются вагоны **двух цветов — жёлтые и красные**.

## Идея

- **Жёлтые вагоны — это разделители** (разграничители между символами).
- **Красные вагоны считаются**: количество красных вагонов в сегменте между жёлтыми разделителями — это **ASCII-код** одного символа.
- Все символы по сегментам, собранные подряд, дают флаг.

```
... R R R R Y R R ... R R ... Y R R R ...
    └── 4 ──┘       └─ ? ─┘    └── 3 ──┘
     chr(4)          chr(?)      chr(3)
```

То есть читаем поток вагонов по порядку: жёлтый = «конец символа / граница», число красных между границами = значение символа.

## Как решать по шагам

1. Распаковать архив, отсортировать видео по имени.
2. Пройтись по видео и выписать последовательность вагонов с их цветом (R — красный, Y — жёлтый). Для подсчёта удобно нарезать кадры:
   ```bash
   ffmpeg -i "video.mp4" -vf fps=5 frames/%04d.png
   ```
3. Разбить последовательность красных по жёлтым разделителям, посчитать длину каждого «красного» участка.
4. Перевести каждую длину в символ (`chr`) и собрать флаг.

## Скрипт-декодер

```python
# seq — последовательность вагонов по порядку: 'R' (красный) и 'Y' (жёлтый-разделитель)
seq = "RRRR" "Y" "RR" "Y"  # ... и так далее

segments = seq.split("Y")              # делим по жёлтым разделителям
counts = [len(s) for s in segments if s != ""]  # число красных в каждом сегменте
flag = "".join(chr(n) for n in counts)
print(counts)
print(flag)
```

Если считать удобнее сразу числами (сколько красных в каждой группе):

```python
red_counts = [75, 85, 66, 83, 84, 85, 123]  # пример: даёт 'KubSTU{'
print("".join(chr(n) for n in red_counts))
```

Проверка: первые группы должны дать `KubSTU{` → `75 85 66 83 84 85 123`.

## Флаг

```
KubSTU{...}
```
> Точное значение зависит от видео из архива. Подставьте посчитанные `red_counts` в скрипт.

## Примечания

- Ключевое отличие от Subway 2/3: тут **два цвета** — жёлтый не считается в значение, а только отбивает границу символа.
- Следите, чтобы пустые сегменты (два жёлтых подряд) не попадали в подсчёт, если по условию они не кодируют `chr(0)`.
