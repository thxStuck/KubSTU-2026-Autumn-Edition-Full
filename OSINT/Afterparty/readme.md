## Шаг 1. Разбираем фото на улики

Сразу выписываем всё, за что можно зацепиться, не только бокал:
- **Бокал-тюльпан и кастомный хайбол.** Форма характерна для авторских коктейлей, не для типового бара/паба.
- **Пламя в отражении бокала** Значит сзади есть что-то похожее на огонь (камин или телевизор).
- **На заднем плане — кальянная колба.** Округлая ёмкость с жидкостью на характерной подставке, силуэт читается уверенно. Заведение почти наверняка кальянная или бар-кальянная.
- **Справа красный кожаный объект.** Похоже на меню в кожаной обложке (потом подтвердится).
- **Свет и фон.** Тёплый низкий свет, деревянная барная мебель — лаундж-формат.

Город можно привязать по контексту: КубГТУ + Информационная безопасность = **Краснодар**.

## Шаг 2. Сужаем географию

Гуглим «барная улица в Краснодаре» / «ресторанная улица в Краснодаре». Стабильно вылезают **ул. Красная** и параллельные ей **Рашпилевская** и **Красноармейская** в центре.

![bar_rest_mile.png](https://github.com/thxStuck/KubSTU-2026-Autumn-Edition/blob/main/OSINT/Afterparty/media/bar_rest_mile.png)

В этой зоне 300+ различных заведений — для перебора слишком много, поэтому фильтруем по уликам со Шага 1.

## Шаг 3. Жёсткая фильтрация

Из всех заведений в центре оставляем только те, что одновременно:
1. **Кальянные / бары с кальяном** (улика — колба на фоне).
2. **Делают авторские коктейли**.
3. **Премиум-сегмент** (по бокалу и оформлению).

После такого фильтра остаётся ~10–15 кандидатов. На этом этапе можно идти двумя путями:
- **Обратный поиск по фото**
- **Прямой поиск** по 2ГИС / Яндекс.Картам

## Шаг 4. Подтверждение заведения

Прогоняем кандидатов через фотогалереи отзывов и официальный контент. Ищем совпадения деталей с исходным фото:

|Улика на исходном фото|Подтверждение в галерее заведения|
|---|---|
|Кальянная колба, подставка|Тот же тип кальяна на других фото|
|Красный кожаный объект|Меню в красной кожаной обложке|
|Деревянная столешница|Барная мебель того же стиля|
|Тики-/керамическая посуда|Видна на других фото из заведения|

Совпадения сходятся на одном месте: **DeepSmoke, Красноармейская ул., 68.**

![cocktail_writeup.png](https://github.com/thxStuck/KubSTU-2026-Autumn-Edition/blob/main/OSINT/Afterparty/media/cocktail_writeup.png)

## Шаг 5. Идентификация коктейля

Открываем меню коктейлей DeepSmoke (меню из фотографий Яндекс Карт). Ищем безалкогольный коктейль в похожем бокале.

Совпадает: **«Танзания»** (non-alcoholic) — японский безалкогольный джин, манговый тоник, сок лайма, сироп кокос.
