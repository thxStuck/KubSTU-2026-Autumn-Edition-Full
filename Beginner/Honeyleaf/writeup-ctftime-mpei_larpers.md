# [Beginner] Honeyleaf  
Инстанс - маленький Flask-сервис «архив чеков пекарни» на  
http://159.194.244.226:8083/. На главной десять файлов: пять чеков и пять  
macOS-хвостов `._*`. В шапке ещё висит ссылка на «Кассу», но живых маршрутов  
всего два: `/` со списком и `/view?file=<имя>`, который показывает файл.

Внутри `/view` путь собирается через `os.path.join(RECEIPTS_DIR, name)`, где  
`name` берётся прямо из query string. Абсолютный путь в `os.path.join` перебивает  
базовую папку, а `../` никто не вырезает. Классическое чтение произвольных файлов:

```bash  
curl 'http://159.194.244.226:8083/view?file=/flag.txt'  
# kubstu{h0n3yl34f_p4th_tr4v3rs4l_defd1128}  
```

Тем же багом вытащил и исходник сервера: `/view?file=/proc/self/cwd/[app.py](http://app.py)`.  
В коде рядом с уязвимым местом даже остался TODO разработчика, что валидацию  
«ещё надо добавить». Для верности проверил ещё `../../../flag.txt` и  
`/proc/self/root/flag.txt` - содержимое то же самое.

Остальное в задаче пустое: чеки сходятся по суммам, `._*` - обычные 177-байтные  
AppleDouble-блоки, ручки `/download`, `/counter`, `/admin`, `/api` отдают 404.  
Флаг отдаёт сам сервис, одного запроса достаточно.

Флаг: `kubstu{h0n3yl34f_p4th_tr4v3rs4l_defd1128}`
