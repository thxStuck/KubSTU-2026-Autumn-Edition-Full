## 🍂 About

**KubSTU CTF 2026 — Autumn Edition** is an international cybersecurity competition hosted by the **Capybaras** team at FITK, Kuban State Technological University. This repository is the **official collection of writeups and challenge materials**: **64 challenges** across **9 categories**, with the original task statements, attached files, and step-by-step solutions.

> Hack for fun, not for profit.

## 📁 Repository layout

Each challenge is laid out so you get both the puzzle and the answer:

```text
<Category>/
└─ <Challenge>/
   ├─ Задание + файл/    ← task statement + attached files
   └─ Решение/           ← writeup / solution
```

Some categories still follow the earlier flat layout (`README.md` / `writeup.md` inside the challenge folder) — we are gradually migrating everything to the structure above.

---

## 🧭 How to use

1. Pick a **category** from the table above.
2. Open a **challenge** folder.
3. Read the **task** in `Задание + файл/`, grab its files, then compare with the **solution** in `Решение/`.
